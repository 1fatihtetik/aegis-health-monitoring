3. KEY DECISIONS (DO NOT REOPEN WITHOUT USER)
- One FastAPI process, two stores (`onboard`, `ground`). Ground is written only by delivered `link/` messages.
- Simulator runs in-process (60s tick, 142d daily history + 48h 1-min prewarm before T0).
- Rules: `THRESHOLD`, `BASELINE` (48h window), `CUMULATIVE`, `COMPOUND` (`all`/`any`/`none`). No `TREND` rule.
- Readiness: 100 at `good`, 50 at `limit`, linear clamped, minus open-alert penalty (`config/readiness.yaml`).
- SPE rule uses area dosimeter: sheltering lowers personal dose (`event_dose_saved_mSv`) without clearing the cabin alert.
- NEW 2026-11-14 Real NASA data (Block R):
  - Fetch once at build time (`scripts/fetch_nasa_data.py`) into `data/nasa/` (checked in); replay offline. Never call DONKI/OSDR/CDAWeb/PDS/Horizons at runtime.
  - Every observation has `provenance`: NASA_MEASURED | NASA_DERIVED | SYNTHETIC_CALIBRATED | SYNTHETIC.
  - Public in-flight astronaut vitals do not exist; crew physiology stays synthetic and is labelled so. Do not claim otherwise in UI, README or pitch.
  - Inspiration4 / OSDR data: aggregate reference ranges only, never a named person's record.
  - A limit becomes `verified: true` only with a document + clause id actually read (e.g. "NASA-STD-3001 Vol 2 Rev D [V2 6004] via OCHMO TB-004").
