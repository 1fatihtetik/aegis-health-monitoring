7. API & WS QUICK REFERENCE (`/api/v1`, `?node=onboard|ground`)
- GETs return `{ node, now, as_of, age_s, ...data }`.
- Block T: `GET /selftests` (catalog with resolved limits + per-field rule limits), `GET /selftests/schedule?crew_id=`
  (onboard; DUE/DONE/OVERDUE/UPCOMING, overdue level INFO), `GET /selftests/results?crew_id=` (onboard, in memory).
  Catalog fields may carry `band` {low, high} (display-only limits) and `anchors`; stand tests add `checkpoints_min`,
  `stop_steps`, params {supine_s, stand_s, min_gravity_g, time_scale}. Stand-test entries below min_gravity_g -> 422.
  Observation adds `entry_method` (CREW_ENTERED only, required there) and `test_id` (value must be a field of that test
  and inside its typing range, else 422). Alert adds `onboard_only`. Ground never receives onboard-only signals/alerts.
- Endpoints: `GET /health`, `GET /crew`, `GET /crew/{id}/summary`, `GET /crew/{id}/timeseries?signal=&from=&to=&max_points=`, `GET /crew/{id}/baselines?window=48h`, `GET /environment/current`, `GET /environment/timeseries?signal=`, `GET /radiation/summary`, `POST /radiation/shelter {crew_id, sheltered}`, `GET /readiness?kind=`, `GET /alerts?state=&severity=`, `POST /alerts/{id}/ack|/treat|/resolve|/note {text}`, `GET /rules`, `GET /limits`, `GET /sim/status`, `POST /sim/scenario {name, seed?, speed?}`, `POST /sim/control {action: pause|resume|speed, speed?}`, `GET /link/status`, `POST /link/blackout {on}`, `POST /link/delay {delay_s|null}`, `POST /link/recommendation {text, checklist?, crew_id?}`, `GET /link/recommendations`, `POST /observations [Observation]`, `GET /datasets`, `GET /spaceweather/event`, `POST /spaceweather/forward {crew_id?}`.
- Provenance objects (snapshot `provenance` map, timeseries `provenance`, alert `evidence`): `{provenance, dataset_id, basis, dataset: {id, label, title, source_url, retrieved, terms, transform, agency} | null}`; timeseries add `segments[]` and `suspect: [[from, to]]`. Observation accepts `provenance` (default SYNTHETIC) + `dataset_id` (required for NASA_* and MEASURED_OTHER); 422 if the label does not match the dataset's manifest `agency`.
- `GET /datasets` -> `{datasets: [{id, tier, title, label, agency, source_url, retrieved, terms, transform, reference, files[{path, sha256_ok}], sha256_ok}], replays: [{id, dataset_id, signals, active, reason}], problems: [], signals: {signal: {provenance, dataset_id, basis}}}`.
- Radiation summary: `replay` {label, dataset_ts, observation_ts, compression, quality, quality_factor, synthetic_spe_overlay} (null when synthetic), `area.dose_rate_absorbed_uGy_h`.
- Link status + WS `link`: `delay_source: {delay_s, provenance, dataset_id, basis, date, dataset}`; snapshot `phase.comm_delay_s` is the live delay, `phase.comm_delay_source` the same object.
- `GET /spaceweather/event` -> `event: {available, event_date, title, provenance, sep[], flares[], cmes[], flux{label, unit, points, suspect, peak_pfu, peak_utc, peak_level}, s_scale[], sources{}, problems[], primary{sep, flare, cme}}`; `POST /spaceweather/forward` -> recommendation payload; 409 if no record.
