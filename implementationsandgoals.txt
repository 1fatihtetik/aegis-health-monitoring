3. KEY DECISIONS (DO NOT REOPEN WITHOUT USER)
- One FastAPI process, two stores (`onboard`, `ground`). Ground is written only by delivered `link/` messages.
- Simulator in-process (60 s tick, 142 d daily history + 48 h 1-min prewarm before T0).
- Rules: THRESHOLD, BASELINE (48 h), CUMULATIVE, COMPOUND (`all`/`any`/`none`). No TREND rule.
- Readiness: 100 at `good`, 50 at `limit`, linear clamped, minus open-alert penalty (`config/readiness.yaml`).
- SPE rule uses the area dosimeter: sheltering lowers personal dose without clearing the cabin alert.
- Data: fetch once at build time into `data/nasa/` (checked in) and replay offline; never call any data service at runtime. Every value has `provenance` (NASA_MEASURED | NASA_DERIVED | SYNTHETIC_CALIBRATED | SYNTHETIC; Block P adds MEASURED_OTHER). Public in-flight astronaut vitals do not exist; crew physiology stays synthetic and is labelled so. OSDR data: aggregate only. A limit is `verified: true` only with a document + clause id actually read.

7. API & WS QUICK REFERENCE (`/api/v1`, `?node=onboard|ground`)
- GETs return `{ node, now, as_of, age_s, ...data }`.
- Endpoints: `GET /health`, `GET /crew`, `GET /crew/{id}/summary`, `GET /crew/{id}/timeseries?signal=&from=&to=&max_points=`, `GET /crew/{id}/baselines?window=48h`, `GET /environment/current`, `GET /environment/timeseries?signal=`, `GET /radiation/summary`, `POST /radiation/shelter {crew_id, sheltered}`, `GET /readiness?kind=`, `GET /alerts?state=&severity=`, `POST /alerts/{id}/ack|/treat|/resolve|/note {text}`, `GET /rules`, `GET /limits`, `GET /sim/status`, `POST /sim/scenario {name, seed?, speed?}`, `POST /sim/control {action: pause|resume|speed, speed?}`, `GET /link/status`, `POST /link/blackout {on}`, `POST /link/delay {delay_s|null}`, `POST /link/recommendation {text, checklist?, crew_id?}`, `GET /link/recommendations`, `POST /observations [Observation]`, `GET /datasets`, `GET /spaceweather/event`, `POST /spaceweather/forward {crew_id?}`.
- Provenance objects (snapshot `provenance` map, timeseries `provenance`, alert `evidence`): `{provenance, dataset_id, basis, dataset: {id, label, title, source_url, retrieved, terms, transform} | null}`; timeseries add `segments[]` and `suspect: [[from, to]]`. Observation accepts `provenance` (default SYNTHETIC) + `dataset_id` (required for NASA_*; also for MEASURED_OTHER after P-0).
- `GET /datasets` -> `{datasets: [{id, tier, title, label, source_url, retrieved, terms, transform, reference, files[{path, sha256_ok}], sha256_ok}], replays: [{id, dataset_id, signals, active, reason}], problems: [], signals: {signal: {provenance, dataset_id, basis}}}`.
- Radiation summary: `replay` {label, dataset_ts, observation_ts, compression, quality, quality_factor, synthetic_spe_overlay} (null when synthetic), `area.dose_rate_absorbed_uGy_h`.
- Link status + WS `link`: `delay_source: {delay_s, provenance, dataset_id, basis, date, dataset}`; snapshot `phase.comm_delay_s` is the live delay, `phase.comm_delay_source` the same object.
- `GET /spaceweather/event` -> `event: {available, event_date, title, provenance, sep[], flares[], cmes[], flux{label, unit, points, suspect, peak_pfu, peak_utc, peak_level}, s_scale[], sources{}, problems[], primary{sep, flare, cme}}`; `POST /spaceweather/forward` -> recommendation payload; 409 if no record.
- WS `/ws/live?node=onboard|ground`: `{type: "snapshot", ...}` (~5/s), `{type: "alert", node, alert}`, `{type: "recommendation", node: "onboard", recommendation}`.
