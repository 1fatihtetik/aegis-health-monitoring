3. KEY DECISIONS (DO NOT REOPEN WITHOUT USER)
- One FastAPI process, two stores; ground is written only by delivered `link/` messages.
- Simulator in-process (60 s tick, 142 d daily history + 48 h 1-min prewarm before T0). Derived signals add no RNG draws.
- Rules: THRESHOLD, BASELINE (48 h), CUMULATIVE, COMPOUND. No TREND rule.
- Readiness: 100 at `good`, 50 at `limit`, linear clamped, minus open-alert penalty. `go_min_ref` makes a Go gate; `hold_rules` force Hold.
- SPE rule uses the area dosimeter: sheltering lowers personal dose without clearing the cabin alert.
- Data fetched once at build time and replayed offline. Every value has `provenance`. Crew physiology stays simulated and is labelled so. OSDR: aggregate only.
- `verified: true` only with a NASA document + revision + clause id that was actually read. Block L changes words, never this rule.
- Block T: results are Observations on the existing path; `CREW_ENTERED` only for UI input; scripted results stay SYNTHETIC; T-4 signals onboard-only.
